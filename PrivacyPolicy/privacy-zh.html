NesTask 隐私政策

English

开发者署名：boluobn
生效日期：2026-11-02。

本政策说明任务文件、购买服务、可选 Agent 连接和本网站如何处理信息。

1. 任务和工作区

任务、描述、进展、标签和附件保存在你选择的工作区；默认是 iCloud Drive，也可使用本机、外置盘或网络卷。NesTask 不提供开发者托管的任务同步服务器。iCloud 同步适用 Apple 隐私政策；其他位置由相应服务处理。

元数据是普通 JSON，附件按文件保存，工作区没有 NesTask 应用级加密。磁盘加密、共享和备份的保护取决于你的系统与服务设置。外观、语言、工作区位置和访问授权等设置保存在本机。

2. 购买与 RevenueCat

NesTask 使用 Apple 应用内购买及 RevenueCat 验证和恢复购买、判断权益，并提供购买分析。应用在启动、周期性权益刷新、购买或恢复时会联系 RevenueCat，不是只在付款时联网。

RevenueCat 处理自动生成的匿名应用用户标识、收据或交易记录、购买历史、权益状态、最近连接时间，以及设备或应用技术信息。匿名标识不代表没有记录，也不保证这些记录永远无法与你关联。根据其说明，IP 可用于推断国家后丢弃。Apple 处理付款；RevenueCat 不收取银行卡信息。

NesTask 的购买验证功能不向 RevenueCat 发送任务正文、附件或工作区路径。RevenueCat 代表开发者处理最终用户数据；其服务可能在你所在地区以外处理数据，详见 RevenueCat 隐私说明。

3. 可选 Agent 连接

此功能默认关闭。启用并批准客户端后，HTTP 接口仅监听本机 127.0.0.1，按授权提供任务、进展、标签及相应附件访问。只读、可编辑和完全控制允许的操作不同。

本机接口不保证后续数据一直留在本机：客户端或模型服务商可能把内容发往云端。Cursor 的 OAuth 回调也可能经 cursor.com 传递授权码及 state、iss；令牌兑换仍在本机并使用 PKCE。第三方后续处理取决于其服务和你的设置。

你可降权、撤销客户端或关闭服务。撤权阻止后续访问，不删除已取得的第三方副本，不撤销已完成操作，也不自动清除本地授权记录和日志。

4. 本机连接记录

授权记录、操作历史与加密恢复日志保存在本机，不放入同步工作区。恢复日志可能含调用参数、计划字段和结果，包括任务标题、备注、进展和附件上传内容；它不同于精简操作历史，不能视为不含正文。

当前实现对操作历史采用 30 天、5,000 条的裁剪范围；新写入会触发普通终态日志超过 7 天的清理。未完成或结果未知的记录不在该清理范围内。这不是到期即全部删除的保证。

Claude 桌面扩展还会将客户端标识与刷新令牌保存在本机受文件权限限制的文件中。卸载扩展不会自动清除该文件，也不等于撤销 NesTask 授权。

5. 删除、支持邮件与请求

删除任务通常将文件夹移入废纸篓；删除标签是标记删除，原定义和关联可能保留。卸载应用不自动清除工作区、购买记录或订阅。你的备份、同步服务和第三方 Agent 副本需分别管理。

来信时，开发者会收到你的邮箱、邮件及主动提供的文件，以处理问题。购买核对可能需要交易编号，从而将相关购买记录与该次请求关联。不要发送密码、令牌或无关私人内容。

购买相关记录在提供和恢复权益、核对交易及履行必要法律义务所需期间保留；支持邮件在处理问题及必要后续联系所需期间保留，不另作营销用途。你可以通过支持邮箱提出访问、更正或删除请求，由我们人工受理。我们会先核实请求与相应记录的关系，并处理我们控制的记录及可向服务商提出的删除；如有必要保留的部分，会说明原因。我们不承诺同时删除 Apple、其他服务商依法保留或由你自行保存的副本。

删除 RevenueCat 客户记录不等于取消 Apple 订阅或删除 Apple 的交易记录。需要取消订阅时，请使用 Apple 提供的入口。

6. 本网站与联系

本网站为静态页面，未添加统计脚本、广告、第三方字体或表单。通过 GitHub Pages 访问时，GitHub 会为安全目的记录访客 IP，是否登录不影响该处理，详见 Pages 说明和 GitHub 隐私声明。外部链接适用对应服务的数据处理说明。

政策变更会在本页更新并标注生效日期。隐私问题和数据请求请通过 支持页面的联系邮箱提出。
